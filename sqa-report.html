Software Quality Assurance Inspection

An Evidence-Based SQA Review and Rework of the Brew Haven Café Web Application

Overview

This evidence-based Software Quality Assurance (SQA) inspection provides a rigorous critical analysis of my own frontend software artifact—the Brew Haven Café Website[cite: 24]. Rather than treating code completion as the final step, this assessment evaluates the application's authentication logic, data integrity, pricing consistency, and mobile responsiveness under realistic user conditions[cite: 24, 25].

The inspection uncovered critical insights, including false-positive feedback loops in mock user authentication, hidden commerce entry points on mobile viewports due to CSS nesting, and decoupled pricing sources prone to synchronization drift[cite: 30, 31]. Following the inspection, systematic code reweworks and regression testing were performed to resolve these structural defects[cite: 38, 44].

Key Inspection Findings

  • Authentication Logic Gap: Discovered that the sign-in handler accepted any input without verifying credentials, issuing a false-positive success notification[cite: 28, 30].
  • Responsive Design Flaw: Identified that nested navigation commerce actions (`.nav-actions`) were inadvertently hidden on smaller viewports (`≤992px`) when collapsing the main menu[cite: 27, 31].
  • Pricing Inconsistency Risk: Noted that product prices were hardcoded separately in HTML labels and inline function calls, creating vulnerability to data drift during promotional updates[cite: 29, 31].

What I Learned

Conducting this SQA review shifted my perspective on software development significantly. I realized that writing code that merely "works on the surface" is insufficient; code must be maintainable, logically sound, and thoroughly tested against edge cases.

Through the rework phases—such as centralizing pricing data using integer centavos, implementing robust PHP-style currency formatting (`Intl.NumberFormat`), and restoring mobile accessibility via a dedicated navigation toggle—I gained hands-on experience in deficit tracking, defensive programming, and rigorous regression validation[cite: 38, 44].
